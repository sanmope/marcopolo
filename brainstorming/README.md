# Brainstorming

Notas libres para pensar las ediciones. Lo que se decide se pasa a `data/viajes.json` y aparece en la página.

## Preguntas abiertas
- ¿Seguimos la ruta en orden (Venecia → … → Génova) o saltamos según la estación del año?
- ¿Recetas "de época" (sin ingredientes americanos: tomate, papa, maíz, ají, maní, cacao) o versiones modernas libres? Puede ser una regla divertida.
- ¿Cada edición la cocina un equipo distinto?
- ¿El número artístico lo hacemos nosotros o invitamos artistas?
- Ideas transversales: pasaporte de Marcopolo que se sella en cada edición; leer un fragmento de *Il Milione* en cada parada.

## Fuente
*El libro de las maravillas* / *Il Milione* — Marco Polo y Rustichello de Pisa (c. 1298).
